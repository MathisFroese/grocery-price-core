# Security policy

This is a local, dependency-free pricing library, not a production service or a source of live store prices. No security support SLA is currently offered.

Do not disclose sensitive findings, personal data, credentials, or exploit steps in public issues. If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** route. Otherwise, first request a private contact channel without posting exploit details.

Never add private Kühlschrank source, personal shopping records, authentic credentials, or non-redistributable retailer data to this repository.
