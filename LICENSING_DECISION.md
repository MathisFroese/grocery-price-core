# Scope of the MIT release

Mathis Froese approved MIT licensing **for this separate Grocery Price Core component**, not for the private Kühlschrank app. The code in this project has its own history and does not include the app's code, retailer scraping integrations, personal household data, or the app's Git history.

The [MIT license](LICENSE) allows third parties to copy, modify and commercially reuse **this published component**, including in proprietary products, while retaining the copyright and license notices. Publishing it does **not** license or publish the separate Kühlschrank product. The terms of any private product remain a separate decision.

Before a release, review every newly added file for ownership and third-party rights. Do not add store logos, screenshots, private credentials, receipts or copied retailer data. This is project documentation, not an individual legal opinion.
